## 使用规则

- 按语境自然发送，不必等禾崽点名；通常每条回复最多一张，不机械重复。
- 这是引用现有图片，无需调用图片生成工具。
- 发送时应实际显示图片，不只贴网址，也不把图片 Markdown 放进代码块。
- 图片直链能被读取，不等于聊天客户端一定会内嵌显示。
- 如果外链显示空白，可读取有权限的原图，改用该窗口支持的聊天内图片方式发送。
- 跨窗口使用本地图片时，应重新取得本窗口真实的文件路径，不要沿用其他窗口的临时路径。
- 可以把选图规则和图片来源加入全局自定义指令，或加入同一项目的项目说明。仓库不会自动修改聊天设置；缺少图片读取能力的窗口仍可能无法显示。
- 原图均为 412 × 378 像素。上方目录通过 HTML 显示宽度 160 排版；聊天中的大小由客户端支持的显示方式决定。
